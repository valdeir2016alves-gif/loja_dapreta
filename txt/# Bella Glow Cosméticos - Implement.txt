# Bella Glow Cosméticos - Implementation Plan

Este documento detalha o plano para construir um e-commerce de cosméticos completo, moderno e estático, otimizado para o GitHub Pages.

## User Review Required

> [!IMPORTANT]
> **Persistência de Dados**: O sistema utilizará `LocalStorage` para o Painel Administrativo. Isso significa que as alterações feitas no `/admin` serão salvas apenas no navegador do usuário que as realizou. Para uma loja real com múltiplos administradores, seria necessário um backend (ex: Firebase, Supabase ou uma API REST). Confirmar se este modelo é suficiente para a fase atual.

> [!TIP]
> **Imagens**: Utilizaremos imagens do Unsplash ou similares para os 20 produtos iniciais para garantir um visual profissional.
